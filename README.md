# AI Basics for Professionals — Resume Book

Резюмета на лекциите, упражнения с примерно решение и подготовка за изпита по курса на SoftUni AI.

Сайтът е само HTML, CSS и JavaScript — без Node, Vite или build стъпка. Отваря се с двоен клик на `index.html`.

## Раздели

- **Лекции** — таб = тема, карти = подтеми.
- **Упражнения** — същите табове; за всяка тема шестте упражнения с условие, насоки и примерно изпълнение.
- **Изпит** — как протича тестът, примерни въпроси и самопроверка с отговори.

Покрити теми от презентациите и упражненията в папката на курса:

1. От промпт към качествен резултат
2. Работа с информация, документи и данни
3. Създаване на професионално съдържание с AI
4. AI в работния ден (уъркшоп)

## Файлове

- `index.html`
- `css/styles.css`
- `js/lectures.js` — резюметата на лекциите (теми и подтеми)
- `js/practice.js` — каталогът на упражненията
- `js/sheets.js` — текстът на упражненията и на изпита в markdown
- `js/markdown.js` — рендира листовете
- `js/app.js` — логиката
- `.nojekyll`, `.gitignore`, `.github/workflows/pages.yml`

Презентациите и `.docx` файловете не се качват — съдържанието вече е в `js/`.

## GitHub Pages

1. Качи файловете в `main`.
2. В репото: **Settings → Pages → Source → GitHub Actions**.
3. След минута-две сайтът е на адреса на Pages.

При всяко следващо качване в `main` сайтът се обновява сам.
